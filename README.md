# A-SOUL Timeline

> 一个为 A-SOUL 粉丝打造的动态聚合与直播日历站点。聚合嘉然、贝拉、乃琳与官方账号的动态，AI 自动识别每周日程表，直播安排自动进日历、可订阅到手机。

**线上地址**：[asoul-timeline.pages.dev](https://asoul-timeline.pages.dev)

## 功能总览

### 📜 动态时间线

按时间倒序展示四位账号的最新动态，支持：

- 视频封面、图文多图、转发原文（含原作者头像）的完整展示
- B 站表情包自动渲染为图片（而非 `[表情名]` 占位文本）
- 图片点击放大、视频封面直达
- 每位成员的专属**应援色**主题——单人动态用个人色，多人联动用团体色，贯穿卡片边框、圆点、标签与昵称
- 点击卡片直达 B 站原动态

### 📅 直播日历

- 月视图 + 任意月份切换，每天用应援色圆点标注当日直播
- 点击日期展开当日时间线，点击条目**直达直播间**
- 近期直播汇总，当天的直播不会遗漏
- 直播条目区分**单播 / 双播 / 团播**，多人直播展示全部参与成员的头像与全名，并跳转到正确的直播间

### 🔴 正在直播

实时展示三位成员的直播状态：开播中的成员以应援色呼吸灯高亮，显示直播标题与观看人数，点击进入直播间。

### 🗓️ 日历订阅

一键复制 ICS 链接，导入苹果日历 / Google 日历，直播安排自动同步到手机。事件带成员名前缀与直播间链接，订阅幂等不重复。

### 🤖 AI 日程识别

官方每周发布的日程表是一张图片。本站通过关键词初筛 + 豆包 Seed 1.8 多模态识图，将图片中的直播安排解析为结构化条目（日期、时间、标题、单播/双播/团播、参与成员），并与动态正文交叉验证直播间归属——团播、双播的跳转链接也能落到正确的直播间。

## 系统架构

```
本地 Mac（常驻任务，30 分钟/轮）         Cloudflare Free Plan
┌──────────────────────────┐           ┌────────────────────┐
│  数据采集服务              │           │  Workers (Hono)     │
│   ├─ 直播状态查询          │  增量推送  │   读 Turso          │
│   ├─ 动态获取（Playwright）│ ────────► │   /api/*            │
│   └─ AI 日程解析           │           └─────────┬──────────┘
└──────────────────────────┘                     │
                                      ┌──────────▼──────────┐
                                      │  Turso（边缘 SQLite）│
                                      └──────────▲──────────┘
                                                 │
                                      ┌──────────┴──────────┐
                                      │  Pages (Astro 静态)  │
                                      │  + SolidJS 岛屿      │
                                      └─────────────────────┘
```

**设计思路：本地负责"脏活"，云端负责"展示"。** B 站接口对数据中心 IP 风控严格，数据获取放在本地（Playwright 驱动真实浏览器环境），采集结果增量推送到 Turso；Workers 只读数据库提供 API，前端纯静态部署到 Pages。

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | Astro + SolidJS islands |
| API | Hono（同一套代码跑 Bun 与 Workers） |
| 数据库 | Turso + Drizzle ORM（本地 bun:sqlite 双模式） |
| 数据采集 | Bun + Playwright |
| AI | 豆包 Seed 1.8（多模态识图） |

## 快速开始

```bash
# 1. 安装依赖
bun install

# 2. 配置环境变量
cp .env.example .env   # 填入 B站 Cookie / 豆包 API Key / Turso 凭据

# 3. 初始化本地数据库
bun db:push

# 4. 启动 API + 前端
bun dev:api
bun dev:web

# 5. 启动数据采集常驻服务（30 分钟/轮，自动同步云端）
cd packages/crawler && bun run daemon
```

## 项目结构

```
│   └── shared/       # 全链路共享类型

```
